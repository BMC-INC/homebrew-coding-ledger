# BMC-INC Homebrew Tap

Formulae for BMC-INC tools.

```bash
brew tap BMC-INC/coding-ledger https://github.com/BMC-INC/homebrew-coding-ledger
brew install coding-ledger
```

Note: the coding-ledger formula downloads the release tarball from the main
repository. It becomes installable by others when BMC-INC/coding-ledger is
public; re-verify the sha256 against the public tarball at that point.
